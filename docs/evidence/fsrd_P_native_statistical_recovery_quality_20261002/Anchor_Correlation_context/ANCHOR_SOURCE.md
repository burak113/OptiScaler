# Current alpha Anchor context (SOURCE only)

Anchor is an existing selective visible-total recovery mechanism, not a new denoiser setting and not the rejected collaborative full replacement. It preserves the original full1 caller demod/remod factors and adds a bounded correction after remodulated RR+Skip. Its suppression is observable but empirical: local RR/reference statistics, seed uncertainty, supported structure and current RR error control transfer. This explains applicability without asserting that it fixes the presently measured illumination/noise conjunction.

## Full Anchor formula and suppression witness

The disabled early return is `FSRDOutputComp.hlsl:675–688`. Classification/domain selection is :698–706, ordinary/light dispatch :710–730. Full handover uses current reference sample G, reconstructed visible RR total R, surface-bounded local moments and a separate 9x9 regional structure/noise support; see :854–927 and :935–1031. Surface support :100–114 uses finite same-sign depth, predicted depth-gradient tolerance, decoded normal agreement and original diffuse material-guide similarity. Neighbourhoods produce statistics, not an averaged replacement reference. Reference NLM is retired (:1078–1081).

At :1100–1134, let muR be local RR RGB mean and vR its variance. Positive Anchor a unconditionally makes `Gbox=clamp(G,max(muR-a*sqrt(vR),0),muR+a*sqrt(vR))`. Additional RGB covariance anchoring (:211–228) rotates into RR's covariance basis, clamps there, then restores the channel box. Its blend permission is current RR/reference palette correlation with bounded decision-history stabilization. Zero Anchor disables these constraints. This box collapses unsupported grain/impulses toward the RR range; it can also restrict genuine new texture or illumination that RR did not carry. Constant local RR gives an exact constant positive-Anchor box.

At :1028–1075, patchNoise comes from reference alpha RMS/lower quartile plus same-surface quiet-pair capping; it is an empirical signal-derived witness, not supplied SDK truth/confidence. At :1088–1102 structure confidence tests current-reference amplitude relative to this noise and brightness; RR agreement tests current reference−RR error against that noise. At :1135–1176 modified SSIM-style luma/chroma agreement K uses local variances/covariances and mean brightness. A supported forward-blur explanation can reduce K (:1158–1167) without widening either Anchor. The base correction is exactly `saturate(detail) * structureWeight * (1-rrAgreement) * (1-saturate(Mix)*K) * (Ganchored-R)`.

Thus already-agreeing RR/reference colour is preferentially retained instead of reprinting reference grain; Mix acts directly on that agreement, not a hidden demod strength. Luma/chroma terms (:1177–1265) can amplify only RR's own correlated high-band pattern within remaining anchored headroom. They cannot create an erased pattern with no RR witness. Final correction is limited to current supported reference/RR range (:1269–1275), weighted by selected domain (:1277–1290), then added to R once (:1295).

Decision reprojection (:276–343) validates motion W, full footprint, depth delta, normals/material/roughness, diffuse guide and current reference colour. It reuses at most .5 with bounded +/- .125 decision deviation; current zero permission cannot be revived. It stabilizes permissions, not previous recovered colour. Reflection/animated-radiance correspondence is not guaranteed by surface motion.

## Light Anchor distinction and quality applicability

`LightAnchorRecovery:371–640` is the existing compact current-frame method. It uses 3x3 local statistics plus radius3 gate-only taps. Alpha uncertainty, quadratic residual, quiet-neighbour pairs, RR unexplained variation and coarse unsupported excursions form patchNoise (:482–540). Its measured-clean verdict requires quiet alpha and five of eight quiet colour neighbours; then structure confidence becomes1, positive Anchor is bypassed and Mix opts out (:490–494,537,550,588). Otherwise the box only relaxes from reference noise-subtracted variance where RR corroborates it (:550–564), and RGB-ray residual-noise suppression applies (:345–353,590). No history is read by this path. This differs from full Anchor's unconditional positive channel box; neither is an independent noise oracle.

The exact observable predicate is :486–494: `quietTolerance=max(length(reference.rgb)*.001,1e-8)` and `cleanStructure=(total>12 && pairCount>=6 && alphaNoise<quietTolerance && quietRunnerUp<quietTolerance && quietNeighbours>=5)`. Here alphaNoise is weighted RMS of nonnegative accepted reference alpha. Accepted colour pairs require neighbourhood weight>.1 and a noncentre neighbour (:426–453); their difference is `sqrt(dot(tap.rgb-reference.rgb,tap.rgb-reference.rgb)/3)`. quietRunnerUp is the second smallest accepted difference; quietNeighbours counts differences<1e-3 (fixed absolute, not quietTolerance). This is measured CLEAN only by that heuristic, never the synthetic truth/noisy-region label. Smooth low-amplitude noise or a biased seed estimate can defeat the predicate; actual clean detail may fail it too.

`docs/fsrd_pipeline_contract.md:213–239,252–299,576–593` already documents reference-denoising retirement, direct Anchor/Mix, possible animated-detail softening, shared Skip noise and decision-only history limits. `docs/fsrd_floor_recovery_release_20260926.md:29–75` names both existing selectable systems and explicitly excludes general game sharpness guarantees. `docs/fsrd_light_anchor_mix.md:18–56` explains the same statistical witness and clean exception; its validation is historical, not a new test here.

The new collaborative fixed-law endpoint closure remains binding: clean static/animated carrier amplitude and material detail were recovered, but noisy/whole physical error worsened. Anchor's existing retention of R and bounded selective transfer is therefore relevant to the unresolved noise-safe correction, whereas that rejected law replaced R everywhere. This is a SOURCE applicability distinction, not proof that applying Anchor to the collaborative estimate passes: its confidence/reference sigma would need a valid observable contract, and the original RR-variance envelope may again obstruct lost illumination. No new operator, dose/guide sweep, test or port is selected by this context note. The material/illumination/detail/noise conjunction and unmeasured stain question remain open.
