# Frozen source context repeat

Four fresh ordinary D3D12 contexts of the pinned native runner, 64 frames each.
Every one of seven native input textures is the exact first-frame bytes of the
retained default-tuning metadata-failed run. All native input frame counts are1;
no frame-to-frame radiance, guide, lighting step, or Monte Carlo field changes.
Frame indices advance normally; only first-frame history reset; identical
camera/jitter controls. Tuning1 applies the runner's existing six fork values.
No conversion calls, provider/binary/shader/production edits or game session.

Retain every actual input, native output, applied controls, stdout/stderr, and
resource guard summary. Authenticate all source files against failure.json and
all applied controls against the earlier exact184-byte/frame payload. Compare
all six repeat pairs in full RGBA and RGB; record earliest differing value/frame
and framewise RMS. A zero observed difference is descriptive for four contexts,
not proof of provider determinism. A nonzero difference would show that changing
input histories are not necessary in this fixture. Neither outcome solves stain
or wave quality or identifies the hidden provider cause.

Guard only each child launched by this script: max240seconds, observed child
working set2GiB, available physical memory floor1GiB, poll.2seconds. Stop this
experiment on guard/native failure; keep partial evidence and do not count a
failed run as64 completed RR calls. GPU-based validation stays disabled.
