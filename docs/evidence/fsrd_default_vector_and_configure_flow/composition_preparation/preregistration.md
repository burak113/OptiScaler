# Fork versus queried SDK defaults: provisional composition protocol

This CPU protocol is prepared before the four native outputs exist. It has
no final source/job freeze, execution readiness or authorization. No GPU,
SDK, build, scorer or device executable is invoked by preparation. Native
creation/recording belongs to the independently owned native preparation.

The native plan is fixed: Fork_r0, AMD_r0, AMD_r1, Fork_r1, 64 source frames,
the same new common EXE and specular input alpha zero. Only the six-scalar
24-byte vector differs. This is not a measured settings response yet.

After completed native seals and an independently passed native postgate
are pinned, compare full 64-frame byte arrays of both RGBA FP16 lobes. The
first exact representative in that fixed order defines each class. No
approximate/RGB-only/framewise deduplication or score-based selection is
allowed. U is 1..4; actual authorized composition needs 64*U fresh helpers,
64*U explicit shader Dispatch calls and 192*U retained output files. Fixed
frame-major, representative-order execution is preregistered. Four logical
cohort rows remain, with omitted metrics explicitly inherited from exact
native-trace equivalence and accompanied by representative/pair byte hashes.
Omitted cohorts are not new measured composition calls or independent samples.

Each frame uses the authenticated original 11-SRV/3-UAV/96-byte CB graph,
128x80, repetition1. Only t0 actual native specular and t2 actual native
diffuse fullRGBA slices change. Other nine fields, depth/history resources,
CB, formats, shader and helper bytes remain exact. Flags8, detail0,
history-valid0 and history-writing0 are unchanged. The inherited 64 original
observed-control replays already passed; this study schedules no new replay.
All three outputs are retained, without caller alpha repair. Historical
source-reference versus actual EXE/CSO compile-provenance qualifications remain.

All nine original frozen metric dictionaries remain historical controls,
without preparation-time rescoring. Four new logical cohort rows are added
later using the original metric function AST/thresholds and the same two
references (constructed raw truth and actual encoded/roundtrip q) and four
windows: full0..63, mature48..63, startup0..7, activation8..15. Actual STD,
signed rank1 Nyquist beta/DC, absolute gain and phase are reported separately.
No oldB scorer is rerun during this preparation. The oldC0 and SpecAlphaA0
comparisons are descriptive historical process/history cohorts, not new
paired controls. Same/new settings contrasts retain within-dose variability.

The correct prior seal schema is `files + external_sources`, not the
historically corrected `external_records` lookup. This has been verified
before any future adapter is frozen. Current reusable sources are byte-exact
snapshots; cardinality/path-only executor/analyzer changes are explicitly
planned and will be diff-pinned later. The helper parser, canonical direct
guard precedence, no-child proof, F-scoped TEMP, 240s/2GiB/minfree1GiB guard
and physical-work checkpoint before metadata/strict acceptance remain unchanged.

Finalization must pin actual native outputs, 184-byte controls, all source
identities, independent postgate, every fullRGBA slice/job, runtime absence,
representative mapping and adapted source diffs. A new final freeze and
independent prelaunch review precede root authorization. The scorer may run
once only after all authorized composition jobs are accepted. Nothing in this
provisional package proves image quality, SDK cause, a vendor bug or a game fix.
