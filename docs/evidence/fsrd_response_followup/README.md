# Response follow-up evidence

`manifest.json` records 928 exact copied files, 89 new completed native contexts
and 5,792 RR dispatches. The archive excludes large NPZ arrays; each retained
external path has a SHA-256 and size. The original native helper's successful
cleanup is separate from array retention: manifests attest consumed texture
hashes, while the two new context-repeat diagnostics also retain original
FP16 lobe bytes and verify them against output hashes.

The new prototypes are test-only. Clean reference enters scores, not pilot or
transfer estimators. Native fixture construction uses labeled synthetic
radiance; historical Joint captures supply geometry/camera/guide evidence, not
independent alpha game truth. Relative quality gates, independent absolute
detail checks and all failed/uncertain results are retained.

To reproduce in this workspace, use the current test modules for the new
prototypes and each study's frozen `source_snapshot` for its original fixture.
Offline source copies record their original paths. Restore support/scripts to
those original `tools_tmp` paths when replaying their imports; the previous
commit's delta-history reference is included under `support`. Do not substitute
an older native pilot response for a newly generated pilot. Reports identify
seed, controls, provider, runner and consumed hashes. A new native replay must
use a new output directory and save its own results; it cannot overwrite these.

The goal remains unachieved. Successful SDK execution and CPU checks do not
establish stain/wave removal, absolute material fidelity, runtime viability or
game acceptance.
