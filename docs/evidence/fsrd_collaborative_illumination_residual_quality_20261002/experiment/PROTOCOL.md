# Fixed collaborative visible illumination variant

SOURCE ONLY, unexecuted. One law, no variants or parameter selection. The previous SDK radiance-guide rejection and simple temporal-mean closure remain binding. This standalone current-frame research operator does not restore the retired DetailReference NLM path.

Interface: `apply_frame(np, C, Qspec, Qdiff, R, geometry_valid, *, linear_depth, normals, depth_gradient, roughness_codes, material_codes)` returns stored HALF RGB promoted to float64 and scalar diagnostics. RGB inputs are decoded stored HALF `(H,W,3)`; geometry arrays have matching extent. Depth is signed linear view depth, normals are decoded directions (normalized internally), gradients are view-depth derivatives per pixel, roughness/material are actual stored 10-bit/2-bit codes. Extent comes only from C; no fixture dimensions, truth, labels, frame index, frequency, noise seed or history enter the operator.

Let M=Qs+Qd, componentwise, and U=C/M. Original caller factors and full1 SDK inputs are not changed. There is no lobe estimate or physical shared-light assumption. Valid estimates FULLY replace R with M times filtered U; this is algebraically a source-domain denoising replacement, not a confidence-certified native residual blend. Do not add Skip again: C and R already represent visible total. Invalid source/factor/geometry, insufficient groups, uncovered pixels or invalid output return exact R atomically across RGB. R itself must be finite, nonnegative, unsaturated decoded HALF. Valid C/Q must be finite nonnegative exact HALF, Q in [0,1], and M positive per channel. Estimated RGB is stored HALF, with negative/nonfinite/saturation rejected, not clamped. Masked computational placeholders are never usable evidence.

Correspondence uses the positive support of current `CompositionSurfaceWeight` guideFlags1 (`FSRDOutputComp.hlsl:100–113`): predicted depth is clamped to +/- .25 abs(z); depth denominator is max(.01 abs(z),1e-3); normal support is squared saturate((dot-.9)*10). Same signed-depth side and exact stored roughness/material compatibility are additionally required for every support pixel. A validity bit alone is insufficient. There is no albedo-pattern veto. The root saved adapter may declare its already-qualified constant surface with exact packed normal/roughness/material provenance; this is not general scene correspondence proof.

Noise law is fixed and observable. For source C, h=(C00-C01-C10+C11)/2 has unit squared coefficient norm. Independent equal-variance Gaussian pixels give Var(h)=v and population median(h^2)=0.4549364231195727 v. For heteroscedastic independent pixels Var(h)=(v00+v01+v10+v11)/4. At each pixel, use the median of the 49 h^2 observations in a same-surface 8x8 source block (origin clamp(pixel-3) inside the image), divided by that fixed Gaussian median, then divide componentwise by M(pixel)^2. No truth or noise-region label enters. Overlapping HH observations are not claimed independent; this median is an empirical local variance estimate, not an unbiased heteroscedastic or lognormal-noise estimator. Source mixed derivatives/material edges, correlated noise, guide uncertainty and non-Gaussian noise can bias it.

Reference patches are 8x8 at stride4. Eligible patches require compatible surface and valid variance at every pixel. Search radius32 is a square in reference-origin coordinates. Rank eligible source-U patches by mean RGB squared difference, then squared origin distance, y, x. Reference is first. Greedily select seven further distinct rectangles that do not overlap any selected rectangle; fewer than eight means baseline fallback for this reference. No distance threshold, fitting, frequency extraction or pilot denoiser is used.

Apply orthonormal DCT-II to both spatial axes and the ordered eight-member group axis, independently per RGB. For fixed membership, fixed M and independent original pixel noise, coefficient variance is sum over g,i,j of D[k,g]^2 D[a,i]^2 D[b,j]^2 V[g,i,j,c]. Pairwise nonoverlap avoids treating repeated pixel observations as independent within a group. Retain coefficients with abs(c)>3 sqrt(variance), also retain zero-variance coefficients, and set others to zero. No special DC preservation. Inverse-transform and retain only the REFERENCE patch estimate.

Overlap aggregation weights each RGB reference estimate by inverse sum of its retained WHOLE-GROUP coefficient variances. This sum is an estimated group noise-energy trace, not calibrated reference uncertainty or native confidence. Zero estimated energy uses a separate equal-average tier dominating positive-energy estimates where present, with no epsilon. Conditional variance formulas do not certify data-dependent matching/shrinkage, estimated-variance randomness, true noise correlations or noisy-factor ratio uncertainty. Even with nonoverlapping members, different groups share observations; aggregation makes no independence claim. Floating DCT implementation and HALF store are a declared CPU schedule, not actual shader arithmetic proof.

This is motivated by the grouping/transform/shrink/inverse/aggregation construction of [Dabov et al. (2007)](https://webpages.tuni.fi/foi/GCF-BM3D/BM3D_TIP_2007.pdf). It is a single hard-transform, nonoverlapping-member, reference-only variant, not exact BM3D or its two-stage Wiener algorithm.

Concrete GPU path: one per-pixel geometry/variance pass, one per stride4 reference for deterministic matching and group transform, then one per-pixel gather over covering reference patches. Reference-only reconstruction avoids foreign-patch scatter atomics. Separate immutable source/factor/geometry SRVs, variance scratch and reference-estimate/weight buffers are required; invalid output selects baseline.
