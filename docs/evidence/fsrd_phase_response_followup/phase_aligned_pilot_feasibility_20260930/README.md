CPU feasibility of a source-only, past-phase aligned spectral pilot

This package freezes one estimator before measurements: history64, minimum8 past observations, lag1 coherence>=.8, debiased RGB signal power>16 nominal noise power, innovation3 RMS, selected coefficient hard support4 RMS, current DC. The estimator accepts only observed RGB and reset/jitter controls. No guide or truth enters it. The exact formula and source hashes are in preregistration.json and results.json.

Thirteen old alpha fixture families were regenerated from SHA-authenticated native snapshot functions and saved seeds. Observed FP16 RGB, clean reference and controls match the retained old sequences exactly. Old native T(P) was never used for the new pilot. Clean reference enters only fixture authentication/construction and scoring. The result is posthoc CPU source feasibility, not an independent native/game acceptance test.

The frozen proposal fails its main purpose: static material and wave source mature temporal standard deviation increase. A genuine slow-phase adversary improves after warmup but early phase and accelerating phase fail. Weak texture startup, colored noise and common source bias remain counterexamples. Relative source gates cannot establish absolute detail fidelity or native response behavior. The compact report records full/mature, startup, per-frame gain/phase, RGB bias, activity and failures without changing thresholds.

The old hard reference uses current-OR-mean support; the preregistered proposal uses selected-coefficient support. Their differences cannot be attributed solely to phase rotation. Nominal variance excludes estimated-phase uncertainty, and effective independent sample count remains unknown. No native run is recommended from this package.

Run with the existing NumPy environment: python analyze.py, then python summarize.py. Both preserve existing result files. Source/history assumptions, signed invalid prediction fallback and selfcheck correction are explicit. No production, shader, registered test, original evidence or GPU operations occurred.
